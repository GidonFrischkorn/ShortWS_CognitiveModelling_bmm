Original object stimuli from Li, Frischkorn, & Oberauer (2026), Experiment 1.

Source: https://osf.io/wpcx5/ (images/image files).
Object size ratings: images/object_size.csv in that project.
The pictures originate from Krasnoff & Oberauer (2023), doi:10.1037/xlm0001211.

PNG transparency defines the object silhouette; retain the grey image background
and set the element background color to tint the object, as in the experiment.
The demonstration uses pairs image1/image5, image2/image8, image24/image4.

Colored SVG variants embed a PNG whose alpha is the inverse of the original
PNG's alpha and whose color is the variant color, so the silhouette is filled
directly. They have transparent backgrounds and do not
use colored rectangle layers in the slides.

Remembered objects: avocado (image1), flamingo (image8), croissant (image4).
The first and third are the smaller members of their pairs; the second is
the larger member. The processing question always asks for the larger object.
The purple test cue probes flamingo.
